# Frontend

Thu muc nay chua giao dien demo local cho AI Assistant tai VinWonders Nam Hoi An.

Hien tai da co `app.py` dung Streamlit de:

- nhap cau hoi hoac chon cau hoi mau
- goi truc tiep `answer_with_rules()`
- hien thi `answer_draft`, confidence, fallback, selected_place, top candidates va debug trace

UI nay van la prototype local, chua dung LLM va chua bat buoc noi qua FastAPI.
